API 키

한 번 넣으면 지울 때까지 유지됩니다. 브라우저나 PC 를 남에게 넘길 때는 지우세요.

이 확장이 쓰는 권한은 하나뿐입니다. 바이낸스 API 키 설정에서 이렇게 두세요.

  • 켤 것 — Enable Reading, Enable Futures
  • 끌 것 — 출금, 현물·마진, 유럽식 옵션, Permits Universal Transfer
  • IP 접근 제한을 걸고, 거래할 심볼만 Symbol Whitelist 에 등록하세요

이체 권한을 끄면 이 키로는 선물 지갑 잔고만 건드릴 수 있습니다. 선물 지갑에 운용액만 두면 최악의 경우가 그 금액으로 닫힙니다.

키는 이 브라우저 프로필에 저장됩니다. 다른 확장은 읽지 못하지만 디스크에는 평문으로 남습니다. 이상하다 싶으면 바이낸스에서 그 키를 삭제하는 것이 가장 확실한 복구입니다.

키를 지워도 이미 걸어 둔 주문은 그대로 남습니다. 취소는 바이낸스 화면이나 패널에서 하세요.
